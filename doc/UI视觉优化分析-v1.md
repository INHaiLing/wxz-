# 专升本语文小程序 UI 视觉优化提案 v1

日期：2026-10-02。基于当前 6 页、本地学习记录和真实模拟器截图分析。本次输出设计方向与概念图，不修改前端样式代码。

## 使用场景与设计判断

当前功能支持三条学习路径：按文学分类/文言篇目系统背诵；每组最多五题的随机复习；回看收藏的薄弱考点。默写隐藏答案供主动回忆，背诵展示答案供核对，收藏与掌握相互独立，继续学习恢复上次位置。

据此提出以下设计假设：用户可能在课间、通勤等短时间内复习，也可能连续阅读较长的文言翻译；前者要求尽快进入题目，后者要求稳定的文字层级和阅读空间。这些是从功能推导的使用假设，尚未经过用户访谈验证。

| 场景 | 用户需要 | 设计响应 |
| --- | --- | --- |
| 打开后继续复习 | 快速找回上次位置 | 首页首张卡放今日目标、上次篇目与继续背诵；倒计时收为次级标签 |
| 按篇学习 | 找到篇目、分清字词与翻译 | 文言目录改为单列，长标题更易读；保留两个专项和状态筛选 |
| 连续阅读长句 | 原文与答案明确，文字不被操作挤压 | 正文建议 17–18px、约 1.7 倍行高；长答案独立浅蓝区域，自然滚动 |
| 切换回忆/核对 | 随时知道当前模式 | 全部学习页面固定左默写、右背诵，使用同一分段控件 |
| 收藏与标记掌握 | 识别两个独立状态 | 暖金星标表示收藏；独立文字按钮与对勾表示掌握 |
| 随机短练 | 清楚本轮进度与下一步 | 缩小随机装饰横幅，保留组号、每组最多五题与末组再练 |

现有视觉问题：首页主要行动在页面下方；亮绿、黄绿、薄荷绿随页面改变；卡片内操作偏小；收藏与掌握均用绿色；长句、分类胶囊和装饰横幅竞争阅读空间。

## 新主题：墨蓝与纸白

采用克制的书卷气，用墨蓝形成统一操作语言，用偏暖纸白承载阅读。颜色选择是审美与信息层级判断，不作为护眼效果的医学结论。

| 用途 | 颜色 | 应用规则 |
| --- | --- | --- |
| 主色 | `#2F4B6E` 墨蓝 | 主要按钮、选中模式、标题与答案强调 |
| 页面底色 | `#F7F5F0` 纸白 | 全页统一；不铺高饱和渐变 |
| 阅读卡片 | `#FFFFFF` | 白色题卡，细边框和轻微或无阴影 |
| 正文 | `#243244` | 长文本；避免浅灰正文 |
| 辅助文字 | `#5D6976` | 描述、组号和次级统计 |
| 答案区域 | `#EDF1F6` | 浅蓝背景配墨蓝答案 |
| 收藏 | `#9B6A2E` 暖金 | 仅用于收藏星标；避免与考试倒计时混用 |
| 已掌握 | `#2F6B55` 青绿 | 配合“已掌握”和对勾；不只靠颜色区分 |
| 分隔 | `#E4E7EB` | 细边框、列表分隔线 |

布局建议：屏幕两侧 20px 左右，题卡内边距 16–20px，卡片圆角约 14px，主要按钮高度至少 44px。收藏图标可以小，但点击区域建议至少 44×44px；这是本方案的操作目标，不是把所有无障碍标准的最低值写成 44px。普通文字对比度按至少 4.5:1 校验，参照 [W3C WCAG 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)；点击区域及间距参照 [W3C Target Size 说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)。生成图的颜色与字号是视觉示意，最终实现需用实际样式值复核。

不增加登录、排名、积分、打卡奖励、输入判分或新的学习模块。长题卡不强行缩小为一屏五题；底部操作需要预留安全区与内容间距。
