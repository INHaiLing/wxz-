# P05：免费试学与学员内容接口

**Date:** 2026-10-02

**Status:** Approved（用户已批准分阶段实施及免费规则）

**Author:** P05 agent

**Reviewers:** 主 agent／权益模块 agent

## Context（背景）

题库已支持草稿与独立发布修订。本模块增加面向甲方学员前端的配置、目录和内容接口，所有题目读取共用同一授权规则。

文学分类和文言篇目各提供一页免费题。文言的常识、字词、翻译共享这一页；页容量由后台配置，不能因为切换题型、详情入口或客户端分页参数得到更多免费内容。

## Functional Requirements（功能要求）

- FR-1: MUST 提供后台单例学习配置：pageSize 初始 20、范围 1～100；dailyTarget 初始 20、范围 1～1000；examDate 初始为空。读取缺省配置不得创建数据。
- FR-2: MUST 仅使用当前可见的发布修订，排除草稿、下架、错误归属和停用目录；排序依据发布 sort_order、稳定题目 ID。
- FR-3: MUST 在每个文学分类／文言篇目全部已发布题型中先取前 pageSize 个，再应用类型过滤；列表及详情复用同一服务，任意已有过滤不能扩大免费集合。
- FR-4: MUST 为匿名和未激活学员仅返回免费题；有效永久权益可读取范围内全部题，撤权后每次重新判断。后台身份／Cookie 不能绕过学员授权。
- FR-5: MUST 提供 GET config/categories/articles/questions/questions/{id}；题目列表明确 source＋categoryId 或 articleId。拒绝未知、重复、空值、无效枚举及客户端 page_size／ordering 参数。
- FR-6: MUST 收费详情返回 403 ENTITLEMENT_REQUIRED，不返回收费题干、答案或正文片段；无效／过期 Bearer 返回 401，不能降级匿名。列表只分页可访问题，附带安全题量和 access 元信息。
- FR-7: MUST 保持已有管理员 Session API 和内容字段契约不变；新增后台配置遵循模型权限和 CSRF，不能删除或新增第二个配置实例。

## Non-Functional Requirements（非功能要求）

- NFR-1 MUST 内容授权在同一 SQL 的相关子查询中先确定全题型免费集合，避免题型排名错误和两次题目查询间发布变化导致错误授权。
- NFR-2 MUST 每次请求读取当前容量、修订及权益，不建立带权益的公开共享缓存；内容分页不超过后台 100 题容量。
- NFR-3 MUST 在 SQLite 和 PostgreSQL 16 跑通新增越权与回归用例；本模块不改认证、权益、根路由及依赖拥有者的文件。

## Acceptance Criteria（验收标准）

### AC-1: (FR-1, FR-7)

Given 无配置行，When 读取配置，Then 返回默认值且数据库仍为空；管理员保存 1／100 容量成功，0／101 和第二个实例被拒绝。

### AC-2: (FR-2, FR-3)

Given 同篇目按序有 word/fact/translation 且题量超过容量，When 分别筛选类型、翻页或请求详情，Then 只读取最先的统一免费题，草稿编辑不改变免费归属或排序。

### AC-3: (FR-4, FR-6)

Given 同学员获得永久来源后被撤销，When 前后请求同一收费题，Then 发放后可读、撤销后 403 且响应不含收费题干或答案；匿名仍只有免费范围。

### AC-4: (FR-5, FR-6)

Given 缺少明确范围或重复／未知／空查询参数，以及失效令牌，When 访问公开学员接口，Then 范围或参数错误为 400、失效身份为 401，不回退宽查询。

### AC-5: (FR-2, FR-3, FR-7)

Given 重新发布、下架或容量变更，When 发起下一次读取，Then 免费集合和目录题量随当前状态变化，历史管理员接口契约及回归保持通过。

## Edge Cases（边界情况）

- EC-1: 目录不存在／停用，已下架题或非法修订引用返回 404，不返回草稿。
- EC-2: 某类型免费题量为零，第一页返回空列表并保留安全 restrictedCount，不给该类型另分免费额度。
- EC-3: 请求超出可访问页数返回 404；不扩大容量或用最后一页别名掩盖无效页码。
- EC-4: 发布内容和客户端续学缓存不同，授权以当前状态为准；后续随机／学习模块必须调用本模块服务。
- EC-5: 旧导入失败页面必须在回滚保存点退出后渲染，不能继续查询坏事务；此阶段共享修复由主 agent 管理，原导入冲突回归用例验证此情况。

## API Contracts（接口契约）

前缀 `/api/student/v1/`，成功字段 camelCase，例如 `GET /api/student/v1/config/`。以下均只读：

| 接口 | 参数 | 成功结果 |
| --- | --- | --- |
| GET config/ | 无 | pageSize、dailyTarget、examDate（YYYY-MM-DD 或 null） |
| GET categories/ | page 可选 | 分页文学分类，id/name/sortOrder/publishedCount/freeCount |
| GET articles/ | page 可选 | 分页文言篇目，id/title/sortOrder/publishedCount/freeCount |
| GET questions/ | source；对应 categoryId/articleId；type/page 可选 | count/next/previous/results/access；count 为可访问题数 |
| GET questions/{id}/ | 无 | 当前发布内容及 access，题目 ID 推导其范围 |

```typescript
type ListAccess = { activated: boolean; pageSize: number; freeCount: number; totalCount: number; restrictedCount: number };
type PublishedQuestion = { id: string; source: "literature"|"classical"; categoryId: string|null; articleId: string|null; type: "fact"|"word"|"translation"; tag: string; stem: string; answers: string[]; sortOrder: number; revision: number };
type DetailAccess = { activated: boolean; free: boolean; pageSize: number };
type Error = { error: { code: string; message: string; fields?: object }; requestId: string };
```

列表 access 中的 freeCount/totalCount 是当前类型筛选后的题量，免费集合在筛选前确定。activated 由永久权益统一服务判定。403 只输出错误和 requestId，不输出收费正文。禁止客户端指定 page_size、ordering、limit 等。

同一请求只进行一次权益判断，并用于内容查询与 activated 元信息。题量分别在请求期间读取，不承诺跨发布变化的事务快照；restrictedCount 最低为 0。实际题目授权及其发布内容仍在同一内容 SQL 中取得，不先取题再靠另一题序查询解锁。

共享服务为 `content.access.published_questions()`、`free_question_ids(source, scope_id)`、`accessible_questions(user, queryset=None)`、`can_access_question(user, question)`；未激活范围约束使用关联子查询。

视图内部 `question_access(user, queryset=None)` 返回（可访查询集、当次 activated），`accessible_questions` 复用同一实现。调用方不能从请求字段传入权益判断结果。

## Data Models（数据模型）

| Field | Type | Constraints |
| --- | --- | --- |
| LearningConfiguration.id | PositiveSmallInteger | 固定 1、主键、数据库单例约束 |
| page_size | PositiveSmallInteger | 默认 20；模型验证及 DB 范围 1～100 |
| daily_target | PositiveSmallInteger | 默认 20；模型验证及 DB 范围 1～1000 |
| exam_date | Date nullable | 默认 null；后台按日期字段编辑 |

不新增题目副本或免费授权记录，免费集合始终根据当前发布与配置计算。

`LearningConfiguration.current()` 返回已保存的 pk=1 配置，缺失时返回未保存默认对象，不进行写入。后续学习偏好和随机模块复用此方法。

## Out of Scope（不在本模块）

- OS-1: 不实现甲方学员前端、微信登录、支付或激活码；分别依赖 P03／P04 等模块的真实服务，不增加运行时替身。
- OS-2: 不改变原管理员接口、正式题库 XLSX 模板或发布行为。
- OS-3: 不在后台配置虚拟支付密钥或存储学习记录，分别由对应业务模块管理。
