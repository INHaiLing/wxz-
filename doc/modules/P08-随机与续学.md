# P08：随机轮次与续学

**Date:** 2026-10-02

**Status:** Approved（用户批准分阶段实施）

**Author:** P08 agent

**Reviewers:** 主 agent／学习模块 agent

## Context（背景）

学员内容已具备统一的免费集合、永久权益和当前发布授权。本模块提供稳定的随机练习以及跨设备续学位置，前端由甲方实现。

随机轮次保存创建时的已授权题目与修订，之后不重排、不补入新题。每次读取还需检查当前发布、分类／篇目和授权，历史轮次不能绕过免费题量或下架。续学只存类型化业务位置，不能保存任意页面路由。

## Functional Requirements（功能要求）

- FR-1: MUST 登录后按明确来源、分类／篇目、可选题型及 writing/reciting 模式创建本人轮次，复用 P05 范围验证与授权。页容量在创建时保存，轮次只包含当时可访问题和发布修订。
- FR-2: MUST 固定轮次题序及 1 起始组号，重复读取和成功请求重试不重洗；每组最多创建时后台页容量。新发布题或容量扩大不能补入旧轮次。
- FR-3: MUST 每读一组重新检查当前题目处于原轮次来源／范围／可选题型并且仍发布、可访问；历史修订属于相同题目才可返回。失效项跳过并解释，不补题或输出受限正文。
- FR-4: MUST 仅本人读取轮次。创建与续学写操作采用 User 锁、Idempotency-Key；同键异载荷 409，重试不新增轮次或恢复旧位置。
- FR-5: MUST GET／PUT 本人续学，保存 source/categoryId/articleId/type/mode/questionId、可空 roundId/groupIndex 与版本。PUT baseVersion 不符返回 409 和 current；随机位置须属于本人轮次、原范围及对应组，顺序题须属于当前范围且可访问。
- FR-6: MUST GET 无位置不写数据；失效位置返回 reason 与可访问起点，不泄露收费内容。保留原位置及版本，不在 GET 自动覆盖学习历史。
- FR-7: MUST 不修改 P07 偏好；模式枚举与现有共享契约、历史前端统一为 writing/reciting，续学切换模式不重洗原轮次。

## Non-Functional Requirements（非功能要求）

- NFR-1 MUST 使用当前内容授权 SQL 判断可访问 ID，再返回该 ID 的固定历史修订；所有回应 private,no-store。限频在业务事务之前计数，失败写入不回滚计数。
- NFR-2 MUST 每轮最多 10000 题，每组最多 100；轮次创建每用户每分钟 10 次、续学写每分钟 60 次、组读取每分钟 120 次。超限 429；不存在题目不创建空轮次。
- NFR-3 MUST 模型约束保护轮次位置唯一、版本正数和类型化范围；后台仅按相应查看权限只读，不提供任意改题序／修订／续学位置入口。
- NFR-4 MUST 用 SQLite 与真实 PostgreSQL 16 验证；并发续学写同版本只能一次成功，同键创建仅一个轮次。

## Acceptance Criteria（验收标准）

### AC-1: (FR-1, FR-2, FR-4)

Given 混合题型的免费范围和幂等键，When 创建／重试并重复读组，Then 保存同一固定题序、修订与容量，不能因切换类型扩大免费题量，也不产生第二个轮次。

### AC-2: (FR-2, FR-3)

Given 已创建轮次，When 题目重新发布、下架、改范围或用户撤权，Then 仍合规题返回旧修订，其余跳过且无正文；新题不补入，配置变化不重分组。

### AC-3: (FR-4, FR-5)

Given 他人轮次或不在所报组的题目，When 读取／保存续学，Then 404／400 且无数据越权；同版本两设备写产生一次成功和一次 409，错误 fields.current 为本人安全位置。

### AC-4: (FR-5, FR-6)

Given 空续学或旧位置已失效，When GET，Then 不创建或修改位置，返回原因与可访起点；撤权后不返回收费题干和答案。

### AC-5: (FR-7)

Given 用户切换 writing/reciting，When 保存同轮次新续学模式，Then 保留固定题序，P07 偏好不被隐式写入。

## Edge Cases（边界情况）

- EC-1: 活跃目录无题返回 404 NO_QUESTIONS；有已发布题但当前类型没有免费题返回 403 ENTITLEMENT_REQUIRED，不创建轮次。
- EC-2: 组号不存在、他人／不存在轮次返回 404；空失效组仍返回原组 metadata 和 skipped，不补入其他题。
- EC-3: 原成功写重试发生在新位置保存之后：只返回原结果及当前位置，不覆盖新版本；发布／权益变化仍影响当前位置有效性。
- EC-4: 位置源目录停用或固定修订错误关联时按失效处理，不输出其他题内容。
- EC-5: 创建范围超过 10000 题返回 400 ROUND_TOO_LARGE，不截断创建不完整轮次。

## API Contracts（接口契约）

前缀 `/api/student/v1/`，Bearer 必须，JSON 输入严格拒绝未知字段与错误类型。

| 接口 | 输入／输出 |
| --- | --- |
| POST /api/student/v1/practice/rounds/ | source、相符 categoryId/articleId、type 可选、mode；Idempotency-Key。返回 id、范围、mode、pageSize、totalCount、groupCount、createdAt |
| GET /api/student/v1/practice/rounds/{uuid}/groups/{index}/ | 无 query；index 从 1 起。返回轮次 metadata、results（固定修订＋position）、skipped（position/reason） |
| GET /api/student/v1/me/resume/ | 无 query；version、resume 可空、valid、reason、start 可空 |
| PUT /api/student/v1/me/resume/ | 范围、mode、questionId、roundId/groupIndex 可空、baseVersion＋幂等键；返回写入结果和 current。重试保留原 version/resume，current 反映当前位置，不恢复历史位置 |

```typescript
type Mode = "writing"|"reciting";
type Context = { source: "literature"|"classical"; categoryId: string|null; articleId: string|null; type: "fact"|"word"|"translation"|null; mode: Mode; questionId: string; roundId: string|null; groupIndex: number|null };
type Resume = { version: number; resume: Context|null; valid: boolean; reason: string|null; start: Context|null };
type Error = {error:{code:string;message:string;fields?:{current?:Resume}};requestId:string};
```

失效原因 UNAVAILABLE／SCOPE_CHANGED／ENTITLEMENT_REQUIRED／ROUND_UNAVAILABLE；无记录 NO_RESUME。顺序起点为当前范围第一道可访问题；随机起点为固定轮次内第一道当前可访问题及其原组。GET 不写版本。409 current 只包含本人位置，不包含收费正文。轮次 mode 为创建记录，续学可保存当前有效模式，显示模式不决定访问权。

## Data Models（数据模型）

| Field | Type | Constraints |
| --- | --- | --- |
| PracticeRound | UUID、user、source、目录、type、mode、group_size、item_count、created_at | 本人所有；类型化范围；固定容量 1～100、题量 1～10000；不可由后台修改 |
| RoundItem | round、position、question、revision | round+position 和 round+question 唯一；position 从 1 起；固定修订必须属于题目 |
| ResumePosition | user、范围、mode、question、round 可空、group_index 可空、version、updated_at | 每用户一条；version≥1；随机组与轮次成对；服务写入和乐观版本 |

## Out of Scope（不在本模块）

- OS-1: 不实现前端、不更新 P07 偏好和统计；默写隐藏答案由甲方前端处理，服务端只返回已授权内容。
- OS-2: 不自动迁移历史无归属的本地存储，不添加任意 route 字段。
- OS-3: 不按随机读取或续学位置增加免费题量，不将历史轮次当成永久授权。

## 实施与验证记录

已实现三个模型、只读后台、四个接口及版本／幂等服务。模式沿用共享契约的 writing（默写）／reciting（背诵）。GET 不写续学或学习偏好；同键轮次重试返回创建结果，组读取仍重新授权。

本机 Python 3.14／SQLite：新增 22 项测试中 20 项通过、2 项 PostgreSQL 专属测试跳过；全量 168 项中 156 项通过、12 项 PostgreSQL 专属跳过。`makemigrations --check --dry-run` 和 `check` 通过；规格校验 100/100。真实 PostgreSQL 16 并发结果、独立评审和 PR 链接完成后补充。

联调步骤：

1. 先发布题库，配置学习页容量；学员取得 Bearer 会话。
2. POST 随机轮次，例如 `{ "source": "classical", "articleId": "quanxue", "mode": "writing" }`，提供唯一 `Idempotency-Key`。保存返回的轮次 id、组数和容量。
3. GET 对应第 1 组，使用 `results` 中的固定 position，保留 `skipped` 提示；不向服务端传递排序或数量参数。空失效组仍可按原组数继续。
4. PUT 续学，首次 `baseVersion: 0`，后续取上次 current.version；随机续学同时提供 roundId、groupIndex，顺序续学均为空。
5. 409 时读取 error.fields.current，由用户选择是否更新；重新提交使用新幂等键和最新版本。网络重试保留原载荷和原幂等键，不覆盖更新后的 current。
6. GET 续学时先判断 valid；失效时显示 reason 并使用 start，start 为空时回到目录。位置仅包含业务字段，不包含任意页面地址或受限正文。

集成入口：注册 `practice.apps.PracticeConfig`，在 `/api/student/v1/` 下包含 `practice.student_urls`，执行 `migrate`。测试隔离设置 `practice.test_settings` 仅供本模块独立测试，正常运行由主项目注册。后台按 Django view 权限查看三个模型，不提供编辑、删除、生成或改序操作。
