## Functional Requirements（3. 功能要求）

- FR-1: MUST 提供本机账号配置工具，录入AppID／OfferID，保存仅含非秘密信息的本机账号档案，记录用户已确认的备案、支付、Apple及成员状态。
- FR-2: MUST 秘密仅使用本机隐藏交互输入；不接受秘密命令行参数，不向stdout／stderr打印秘密、秘密摘要或外部异常文本。非TTY时拒绝隐藏输入，不能降级为明文。
- FR-3: MUST 保留既有Django密钥、会话加密密钥及不相关配置；只补缺失字段。重复执行保留已填秘密；用户主动更新秘密才替换目标字段。写入失败、无效输入或并发文件变化不得留下部分配置。
- FR-4: MUST 本轮账号准备保持支付总开关与Android／iOS新销售关闭；已有有效配置或已关联另一AppID时拒绝静默切换，不调用发权、联网查单或发货。
- FR-5: MUST 自动补齐缺失会话Fernet密钥前确认不存在需要旧密钥解密的数据；存在加密会话或支付令牌缓存时拒绝自动换钥。已配置密钥永不自动轮换。
- FR-6: MUST 提供只读离线诊断，检查账号标识、秘密存在与结构、Fernet往返、支付安全信封、迁移、角色、商品价格／映射／同步及数据库类型，给出稳定检查码和已就绪／缺失／待外部验收状态。
- FR-7: MUST 诊断不联网、不写业务数据，不临时打开支付开关；不能将字段已填写、人工平台确认或SQLite测试写成真实微信／Apple／PG并发验收通过。
- FR-8: MUST 保留后台及学员HTTP契约；本轮只新增CLI和本机配置资料。商品仍由后台人员核对平台商品并受权限确认同步，不因档案自动标记已同步。
- FR-9: MUST 更新RRD、联调手册、快速清单、开发任务和交付记录，去除把当前账号备案／虚拟支付／Apple状态写成未完成的过期陈述，保留类目待核实与真实渠道待验收。
- FR-10: MUST 实际本机数据库升级前创建不覆盖的备份，执行既有迁移、初始化分权和单商品，保留管理员、题库及手工修改；不设置默认管理员密码。

## Non-Functional Requirements（4. 非功能要求）

- NFR-1: MUST 所有新增工具默认不进行外部网络请求；秘密与档案文件只在.gitignore覆盖的.env／.local中，不生成明文秘密备份。POSIX文件0600，Windows说明本机账户文件权限边界。
- NFR-2: MUST 单次配置以完整校验后原子替换方式提交，并检查目标读取后未发生变化；拒绝符号链接目标及重复关键配置歧义，报错不输出原始文件内容。
- NFR-3: MUST 只读诊断可在Windows／Linux执行，缺迁移、无管理员、无商品或无秘密时给出安全状态而非泄密异常栈；一般离线检查不超过10秒，数据库不可达使用有限超时／安全错误码。

## Acceptance Criteria（5. 验收条件）

### AC-1:

Given 新建或旧版本机.env，When 配置已确认账号，Then 补齐缺失字段与安全密钥，支付三开关关闭，档案不含秘密；重复执行保持既有秘密及不相关设置。(FR-1, FR-3, FR-4)
### AC-2:

Given 用户在TTY隐藏录入秘密，When 输入有效，Then 仅私有.env更新；无TTY、无效输入、重复字段、换账号、并发变化或写入失败时整次拒绝且不输出秘密。(FR-2, FR-3，NFR-1, FR-2)
### AC-3:

Given 已有加密会话或令牌缓存且会话密钥缺失，When 配置工具运行，Then 拒绝自动生成新密钥并提示恢复原密钥。(FR-5)
### AC-4:

Given 部分配置及未迁移／不可达数据库，When 离线诊断，Then 报告缺口且不泄密、不联网、不写业务、不更改销售开关，不把外部状态误报为已验收。(FR-6, FR-7，NFR-3)
### AC-5:

Given 完整结构配置与已初始化本机库，When 诊断，Then 本机项可通过但真实登录、商品平台核对、HTTPS回调与真机支付仍按证据列为待验收。(FR-6, FR-7, FR-8)
### AC-6:

Given 当前旧版实际SQLite库，When 先备份再迁移和初始化，Then 保留原有数据，商业表及权限、商品就绪；原后台、学员及历史前端回归继续通过。(FR-9, FR-10)

## Edge Cases（6. 边界与异常）

- EC-1: 用户只提供账号标识，不提供秘密：保存标识并报告秘密缺失，禁止模拟登录／付款成功。
- EC-2: 平台已开但本机渠道关闭：分别呈现平台人工确认与本机销售状态；不自动开启。
- EC-3: 账号已绑定另一应用、活动交易或旧加密数据：不跨AppID继承openid／Bearer／订单，不自动改密钥，保留原文件。
- EC-4: Secret可能包含美元符号或引号：写入及解析不做变量插值，拒绝换行／控制字符；不会通过Shell拼接传秘密。
- EC-5: 未配置公网域名、服务器或甲方前端：本轮只本机运行；开发者工具本机测试与实际手机HTTPS／微信回调明确区分。
- EC-6: Apple退款问询只采用已批准官方不确定兜底；不擅自制定同意／拒绝退款策略。
