# P07：学习状态、收藏与统计

**Author:** P07 开发 agent；评审：主 agent／其他开发 agent。

**Date:** 2026-10-02

**Status:** Implemented（已实现并完成本地验证）；PostgreSQL 并发及 PR 交叉审核待 CI。

## Context（背景）

学员前端由甲方开发，后端负责按账号保存收藏、掌握、目标和学习统计。题目状态关联稳定 ID，重新发布不会清除学习历史。

多设备采用版本校验，网络重试采用公共幂等记录。免费、权益和下架授权统一复用 P05 内容服务，不在学习模块重复定义授权。

## Functional Requirements（功能要求）

- FR-1: MUST 收藏和掌握独立，显式 PUT 至少一个 boolean；baseVersion 为当前版本，缺省状态版本 0，成功由服务器递增。
- FR-2: MUST 写操作先锁 User，再查公共幂等记录、比较当前版本、授权和写入。相同键同载荷返回历史成功，不重复应用；同键异载荷或版本冲突 409，版本冲突包含本人当前状态。
- FR-3: MUST 新建状态或新增 true 时逐题授权；无权／下架题只能操作本人已有状态且不能新开 true。已有收藏和掌握可取消，历史活动保留，不返回收费正文。
- FR-4: MUST 当 mastered 从 false 变为 true 时，按服务端上海日期记录活动；同用户同题同日唯一，取消后重掌握、重试及重新发布不能重复计数。
- FR-5: MUST 统计当前有效已发布题总数及其中掌握数、今日活动题数、学习天数和完整掌握篇目数。空篇目不完成，文言非空篇目所有当前题掌握才完成；下架不删除历史活动。
- FR-6: MUST 收藏列表分页本人状态，只有授权题返回当前完整发布内容；其他项只返回本人状态、questionId、null 正文及不可用原因。每页容量取后台配置，不能由客户端放大。
- FR-7: MUST 保存 writing／reciting 学习模式和每日目标；缺省 GET 不写库，目标取后台默认，PUT 版本及幂等规则与题目状态一致。
- FR-8: MUST 逐题 GET 本人状态用于新设备初始化；可访问题无记录时返回 false／false／version0 且不写库，失权或下架后仅返回本人已有状态。无本人记录的受限题拒绝访问，不返回正文。

## Non-Functional Requirements（非功能要求）

- NFR-1 MUST 账号隔离、Bearer 严格验证；只读后台保留历史，学习接口使用 private/no-store 和 Authorization/Cookie Vary。
- NFR-2 MUST SQLite 回归和真实 PostgreSQL 独立连接竞争验证；两设备同版本仅一个写入，相同幂等请求只写一次状态和活动。
- NFR-3 MUST 外部 PUT 校验严格 JSON boolean／integer，拒绝未知字段、未知分页、重复参数；单页最大 100，不建立运行时替身。

## Acceptance Criteria（验收标准）

### AC-1: (FR-1, FR-2, NFR-2)

Given 两设备同版本，When 竞争 PUT，Then 一个成功一个 409；同请求重试返回历史且不再次更改状态，同键不同内容 409。

### AC-2: (FR-3, FR-6, NFR-1)

Given 本人收藏收费题后撤权／下架，When 查看收藏或取消状态，Then 正文为 null、历史保留且可取消；其他账号无该记录，不能新增受限 true。

### AC-3: (FR-4, FR-5)

Given 上海跨日、取消重掌握及题目重新发布，When 写入学习活动和统计，Then 日期按服务端上海日、同日同题一次，掌握状态保留、统计分母使用当前发布内容且空篇目不完成。

### AC-4: (FR-7, NFR-3)

Given 缺省偏好、非法目标／模式／类型和旧版本，When GET／PUT 偏好，Then GET 不写库、合法配置成功、非法参数 400、旧版本 409 且返回当前偏好。

### AC-5: (FR-8, NFR-1)

Given 新设备、其他账号及失权题，When 读取逐题状态，Then 返回本人当前版本，可访问题默认值不写库；失权仅允许本人已有状态且不含正文，其他账号无法读取该记录。

## Edge Cases（边界情况）

- EC-1: 状态不存在用版本 0；未授权时不能借 false 创建受限题的状态。
- EC-2: 历史成功请求在后续取消状态或撤权后重放，只返回历史状态，不再次改状态或记录活动。
- EC-3: 取消掌握不扣除已发生学习活动；统计掌握比例只算当前发布题，学习天数仍包含历史日期。
- EC-4: 发布版本或题目归属变化不改变稳定题目状态；收藏正文读当前发布修订。
- EC-5: 今日学习按服务器确认日计算，不能由客户端传日期补刷统计。

## API Contracts（接口契约）

前缀 `/api/student/v1/`；全部需要学员 Bearer，PUT 带 `Idempotency-Key`。

| 接口 | 输入／结果 |
| --- | --- |
| GET /api/student/v1/me/questions/{id}/state/ | 本人状态；默认版本 0，不写库；已有状态失权后仍可读 |
| PUT /api/student/v1/me/questions/{id}/state/ | `{favorite?,mastered?,baseVersion}` → QuestionState |
| GET /api/student/v1/me/favorites/ | page 可选；分页 FavoriteItem，count 为本人收藏数，包含不可用占位项 |
| GET /api/student/v1/me/statistics/ | totalQuestions/masteredQuestions/masteredPercent/todayQuestions/studyDays/completedArticles/dailyTarget |
| GET /api/student/v1/me/preferences/ | GET Preference |
| PUT /api/student/v1/me/preferences/ | `{mode?,dailyTarget?,baseVersion}`，至少一个偏好字段 |

```typescript
interface QuestionState { questionId: string; favorite: boolean; mastered: boolean; version: number }
interface Preference { mode: "writing"|"reciting"; dailyTarget: number; version: number }
interface FavoriteItem { state: QuestionState; question: object|null; unavailableReason: "ENTITLEMENT_REQUIRED"|"CONTENT_UNAVAILABLE"|null }
interface Error { error: { code: string; message: string; fields?: { current?: QuestionState|Preference } }; requestId: string }
```

成功 PUT／GET 200；masteredPercent 为 0～100，保留两位小数，无发布题时为 0。400 为非法字段／缺幂等键，401 为无效身份，403 ENTITLEMENT_REQUIRED 为新增受限状态或受限题无本人记录时读取，404 为未知题目或无效页，409 VERSION_CONFLICT／IDEMPOTENCY_CONFLICT。受限收藏不返回题干、答案、标题、归属或标签。

## Data Models（数据模型）

| 实体 | 字段 | 约束 |
| --- | --- | --- |
| QuestionState | user、question、favorite、mastered、version、updated_at | user+question 唯一；version ≥0；FK PROTECT |
| LearningActivity | user、question、study_date、created_at | user+question+上海日期唯一；FK PROTECT |
| LearningPreference | user、mode、daily_target、version、updated_at | user 唯一；mode writing／reciting；目标 1～1000；version ≥0 |

## 操作与验收记录

后台模型只读；学习状态通过本人 API 写入。根应用与路由由主 agent 注册，并随模块提交。没有学员前端或默认管理员密码。

学员前端对每次新 PUT 生成新的 `Idempotency-Key`；相同成功请求的网络重试保留原 key、载荷和 baseVersion。409 VERSION_CONFLICT 的 `fields.current` 为本人当前状态，version 为数字、favorite/mastered 为布尔值；更新展示后使用新 key 和当前版本发起新操作。成功历史重放的响应可能早于当前状态，不表示服务器再次应用了旧动作。

```http
PUT /api/student/v1/me/questions/first/state/
Authorization: Bearer <学员令牌>
Idempotency-Key: state-request-001
Content-Type: application/json

{"favorite":true,"mastered":true,"baseVersion":0}
```

后台学习容量和缺省每日目标来自「学习配置」。调整缺省目标只影响尚无偏好的账号；调整容量或撤权后，下次收藏读取重新鉴权，受限项保留本人原题目 ID 便于取消，正文为 null。
