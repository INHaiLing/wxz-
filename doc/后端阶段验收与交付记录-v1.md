# 后端阶段验收与交付记录

日期2026-10-02；开发版本0.4.0。P01～P12代码、模块说明、测试与交叉审核已完成，各模块PR已整合进阶段分支。尚未合入main、未创建新阶段标签、未部署公网；真实微信及甲方前端联合验收单列。

## 可用功能

- Web后台：管理员登录与分权、题库编辑／XLSX预检导入、签名发布确认、独立修订和下架；同页并发修改不会静默覆盖。
- 学员服务：微信身份与7天独立Bearer、专用启停入口；统一文学分类／文言篇目第一页试学，所有内容入口鉴权。
- 权益与发码：10元初值单商品、永久权益及来源、一次CSV领取后启用、永久兑换、已激活不消费新码、带理由预览撤销误发来源；原码仅存摘要和掩码。
- 学习：收藏／掌握独立版本、上海日期统计、偏好、固定随机轮次及发布引用、类型化续学和失效位置处理。
- 交易：订单成交快照、每设备准确签名、开通占位、AES安全平台通知、查单／发货／退款、租约重试和受控人工核查。
- 运维：强制安全生产设置、非root Gunicorn／Nginx及systemd模板、六组业务权限、日志脱敏、数据库就绪、拒覆盖备份恢复和实际迁移演练。

## PR及版本管理

模块链接和各次审核证据见[阶段任务表](后端开发阶段与任务.md)及[模块说明](modules/)。每模块独立branch／worktree；共享路由／配置由主agent整合。模块PR已合阶段分支，阶段PR按依赖堆叠，审核时顺序为[基础#1](https://github.com/INHaiLing/wxz-/pull/1)→[第0批#4](https://github.com/INHaiLing/wxz-/pull/4)→[第1批#7](https://github.com/INHaiLing/wxz-/pull/7)→[第2批#13](https://github.com/INHaiLing/wxz-/pull/13)→[第3批#17](https://github.com/INHaiLing/wxz-/pull/17)→[第4批#18](https://github.com/INHaiLing/wxz-/pull/18)。前置合并后再调整下一PR基线；保留历史提交与标签，不强推或覆盖历史。

每阶段合入主分支后才创建对应版本标签；尚未触发此步骤。当前0.4.0源码和文档已推GitHub，真实上线验收完成后才进入1.0.0。

## 使用与交接文件

初次本机启动在仓库根目录运行 `./backend/setup.ps1` 和 `./backend/start.ps1`，管理员自行建立，无预设密码。后台 `http://127.0.0.1:8000/admin/`；本机演示16题默认是草稿，先发布才能从学员内容接口读取。实际微信登录需要甲方AppID与私有AppSecret，不能用游客AppID或运行时假登录代替。
