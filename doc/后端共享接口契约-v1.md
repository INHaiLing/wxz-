# 后端共享接口契约 v1

2026-10-02；实施规格已批准。以下新增接口为实施契约，实际可用状态见模块说明及任务表。原 `/api/v1/` 后台接口不变。

## 接口与认证

新增路径前缀 `/api/student/v1/`，末尾带 `/`，JSON 字段保持 camelCase。目录、配置和免费顺序题匿名可读；带有非法／过期 Authorization 时必须 401，不能匿名降级。其余接口使用 `Authorization: Bearer <随机会话>`，不接受后台 Cookie 代替学员身份。鉴权成功仍执行逐题授权，后台角色不提供学员绕过。

| 方法／相对路径 | 模块 | 约定 |
| --- | --- | --- |
| POST auth/wechat/ | P03 | `{code}`；服务端换取微信身份；返回 `{token,expiresAt,user:{id}}` |
| POST auth/logout/ | P03 | 撤销当前会话，204 |
| GET config/ | P05 | 学习页容量、每日目标、可空考试日期；不返回密钥 |
| GET categories/、articles/ | P05 | 启用目录、已发布题量和免费题量 |
| GET questions/、questions/{id}/ | P05 | source/categoryId/articleId/type/page；容量由后台决定，禁止客户端指定 page_size/ordering |
| GET products/ | P04 | 全题库单商品、金额分、永久规则、渠道可购买状态 |
| GET me/entitlements/ | P04 | 当前全题库权益，不泄露原码或支付密钥 |
| POST activation/redeem/ | P06 | `{code}`＋Idempotency-Key；返回兑换历史结果及当前权益 |
| POST orders/ | P09 | `{productId}`＋Idempotency-Key；创建本人本地待支付订单；尚未签发参数时不阻止兑换 |
| GET orders/、orders/{id}/ | P09 | 只查本人，历史金额及状态；不依客户端字段确认付款 |
| POST orders/{id}/payment/ | P09 | `{platform:"android"|"ios"}`＋Idempotency-Key；官方签名参数；未启用渠道明确拒绝 |
| POST orders/{id}/query/ | P10 | 查询本人订单的平台状态；限频；统一确认服务 |
| PUT me/questions/{id}/state/ | P07 | `{favorite?,mastered?,baseVersion}`＋Idempotency-Key；显式赋值 |

| GET practice/rounds/{id}/groups/{index}/ | P08 | 本人轮次、1 起始组号；稳定题序，重新鉴权 |
| GET／PUT me/resume/ | P08 | 类型化范围、questionId、mode、可空 roundId；PUT 版本和幂等键 |

支付消息独立入口 `/integrations/wechat/virtual-payment/`，按官方安全模式验签与解密；不能使用学员 Bearer 或普通微信支付 V3 通知方式。

新增学员接口错误：`{error:{code,message,fields?},requestId}`；成功无强制包装，列表统一 `{count,next,previous,results}`，额外授权元信息使用 `access`。404 不透露其他账号数据，401 为认证失败，403 为权限或权益不足，409 为版本／幂等／已激活／在途冲突，503 为外部能力不可用。原后台错误处理不变。

## 服务、事务与幂等

公共层 `common` 提供 `BusinessError(code,message,status=400,fields=None)`、学生视图错误处理、请求 ID、共享限频及 `IdempotencyRecord(user,operation,key,request_digest,response)`。业务请求以稳定 JSON 摘要比对；键 8～128 个 ASCII 字母／数字／`._:-`；同用户同操作同键唯一，同键不同载荷 409。原成功重试重新附加当前权益，不重复写来源。

权益模块 `entitlements` 公开：

```python
SCOPE = "all_chinese"
has_active_entitlement(user, scope=SCOPE) -> bool
entitlement_snapshot(user, scope=SCOPE) -> dict
lock_user(user_or_id) -> User  # 必须处于 atomic，先锁现成 User 行
grant_entitlement(user, source_type, source_id, actor=None, scope=SCOPE) -> EntitlementSource
revoke_entitlement(source_id, actor, reason, expected_fingerprint=None) -> EntitlementSource
```

永久来源 `source_type` 为 `activation` 或 `payment`，来源类型＋业务 ID 唯一。发放及撤销按 user→OpeningReservation→业务订单／码→来源顺序加锁；同一来源撤销后不能被重新激活。`OpeningReservation` 由权益模块拥有，`user+scope` 唯一，通过统一服务 reserve/release。支付准备必须在官方签名响应可能离开服务端前持久化占位；仅创建本地订单或准备能力失败不创建阻塞占位。签发后不能仅依据客户端取消、本地过期或平台暂查不到订单释放。统一活动审计由权益模块拥有。

权益发放原语保证来源幂等；新开通入口负责锁内检查已有权益，支付已付冲突保留订单待核查。开发中禁止通过后台任意添加“付款成功”或手工改来源状态绕过服务。

题库模块 `content.access` 公开：

```python
published_questions() -> QuerySet[Question]
free_question_ids(source, scope_id) -> list[str]
can_access_question(user, question) -> bool
accessible_questions(user, queryset=None) -> QuerySet[Question]
```

免费 ID 必须先在整分类／篇目的全部已发布题中取前 N 个，之后才筛选题型。不可在 ORM 排名查询之前应用 type 条件。发布修订、目录启用、容量变更在每次新请求重新计算；不能共享带权益的公开缓存。

## 学习与价格默认

学习每日目标初值 20；考试日期为空。收藏和掌握互不影响；版本由服务器递增。掌握比例分母是当前全部已发布题，今日学习为当天首次掌握题目数（用户＋题目＋上海日期去重），离线提交按服务端确认日。旧状态／活动保留，失去权限后可取消已有收藏／掌握，不可新增受限状态。

顺序续学按当前发布排序重新定位；随机轮次固定题目和修订，不自动加入新题；下架／失去授权的项跳过且说明原因。历史修订读取仅限当前仍可访问的相同题目，免费范围及已发布状态按当前状态检查。

商品初始金额 1000 分；改价后保存平台同步状态，新的线上购买要求本地与平台商品配置匹配。价格、商品及永久规则写入订单快照，不能更新历史成交。
