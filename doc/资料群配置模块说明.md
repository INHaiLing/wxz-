# 资料群配置模块

本模块在 Django 管理后台维护一条资料群配置，并提供公开学员查询接口。管理员可修改微信群二维码、微信号、领取口令、资料说明、群公告和启用状态；学员接口只返回启用配置。未配置或停用时返回 `{"enabled": false}`。

## 接口

`GET /api/student/v1/resources/group/`

成功响应包含 `enabled`、`groupQrCode`、`wechatId`、`claimCode`、`description`、`announcement`、`updatedAt`。二维码 URL 由 Django storage 的 `MEDIA_URL` 生成，不暴露服务器文件系统路径。公开接口允许匿名访问，但显式提供无效 Bearer 凭证仍会返回 401。

## 管理与上传

后台模型权限为 `view_groupresourceconfiguration` 和 `change_groupresourceconfiguration`；通过 `change_groupresourceconfiguration` 控制修改权限，配置只能保留一条且不能删除。普通业务查看角色如需查看后台配置，需要管理员另行授予查看权限。

二维码仅接受扩展名、上传 MIME 类型和文件签名相符的 PNG、JPEG 或 WebP 文件，大小上限为 2 MiB。文件写入 `MEDIA_ROOT/resources/group/`，系统会生成随机文件名。

## 部署媒体文件

本机默认 `MEDIA_ROOT=backend/.local/media`、`MEDIA_URL=/media/`。生产 `MEDIA_ROOT` 默认为 `/var/lib/chinese-study/media`；部署时应将其设为独立、持久化且可备份的媒体目录，并创建该目录供应用写入、供 Nginx 读取。上传存储会将其下的 `resources/group/` 和 `resources/` 设为可遍历目录、二维码文件设为只读公开文件；不会调整媒体根目录或其上级目录权限。Nginx 只为 `/media/resources/group/` 配置只读文件映射到该目录，确认 Nginx 账号可遍历路径各级目录；不能把 `MEDIA_ROOT` 指向导入暂存区或数据库备份目录。生产设置和 Nginx 模板的实际挂载尚未在真实服务器验证。
