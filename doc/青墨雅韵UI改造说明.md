# 青墨雅韵 UI 改造说明

日期：2026-10-02。用户已确认 `doc/设计参考/青墨雅韵-v2.png`，本轮将该视觉方案应用于全部 6 个原生小程序页面。

## 设计基准

- 黛绿主色 `#1B4D3E`，主按钮/选中态 `#13382D`，纸白底色 `#F7F8F5`，白色卡片。
- 正文 `#242A27`，辅助文字 `#5C6460`，琥珀 `#C47A2B` 用于倒计时和收藏；已掌握使用青绿与文字/对勾。
- 标题优先本地宋体，正文使用系统无衬线；不依赖网络字体。主要正文约 32–34rpx，行高 1.75。
- 卡片圆角统一 24/32rpx；采用轻边框、轻阴影和合理留白。
- 首页采用纸白导航；其他页统一黛绿导航。导航高度与胶囊避让根据微信实际尺寸计算。
- 模式开关统一为左「默写自测」、右「背诵全览」。答案用浅竹青底色强调；翻译题在背诵模式分原文与参考译文。
- 收藏和掌握使用独立操作；默写模式不展示答案，不加入输入判分。
- 页面底栏固定时，正文预留对应高度与底部安全区；长文本自然滚动。

1. 检查 6 页和 5 个公共组件全部使用新主题，避免旧亮绿/橄榄绿残留。
2. 执行现有业务测试、工程校验、微信 WXML/WXSS 原生编译。
3. 检查默写答案隐藏、背诵答案高亮、翻译长句、收藏/掌握与原有分页行为。
4. 在真实微信开发者工具中检查首页、文学、目录、弹窗、字词、翻译、随机、收藏、空态与底部安全区，保存新版实际截图。
5. 记录实际完成的验证、工具限制和剩余差异；新截图与历史验收资料分开保存。

## 验证边界

- 本次为微信开发者工具模拟器验收，尚未进行手机真机验收；字体及微信原生胶囊/状态栏由设备环境决定，不承诺与生成效果图逐像素一致。
- 本机游客项目的自动化服务连接在 12 秒超时后停止，实际页面检查采用真实 GUI 操作。控制台最终为 0 错误、6 警告；可见警告含游客模式 API 模拟返回和基础库 API 提示，未将全部警告判定为无害。
- 开发者工具中途出现一次路由已变化但画面滞后的情况，重新编译后恢复，后续返回导航正常；保留该环境现象记录，未据此改写路由逻辑。
- 数据仍为现有演示题；25 条目录并非完整正式考纲题库。示例考试日期、本地存储和其他既有功能边界见项目 README。本轮仅改前端，没有接入后端。
