# 应用文模块说明 v1

本模块用于管理和展示应用文学习内容，包含四种类型：写作模板、范文示例、历年真题、专项练习。

## 后台功能

- 管理应用文分类和文种。
- 新增、修改、排序和预览应用文内容。
- 内容保存为纯文本，支持换行。
- 专项练习填写题目和参考答案；第一版不保存学员作答、不做作文批改。
- 内容先保存为草稿，发布后才出现在学员接口；下架会保留历史版本。
- 已发布内容保存独立修订，修改草稿不会改变当前已发布内容。
- 编辑、发布和下架使用后台权限；发布和下架写入后台审计日志。

## 学员接口

接口前缀：`/api/student/v1/`。

```text
GET /writings/
GET /writings/{id}/
```

列表支持 `categoryId`、`genreId`、`kind`、`page` 筛选。内容按分类排序，每个分类按后台 `pageSize` 取首屏免费内容；模板、范文、真题和专项练习共用同一免费集合，切换类型不会增加免费数量。

未登录用户可以读取免费内容。已购买或兑换永久权益的学员可以读取全部已发布内容。未发布、下架、停用分类或停用文种的内容不会返回；访问收费详情时只返回统一的 `ENTITLEMENT_REQUIRED` 错误，不返回正文或参考答案。

列表内容字段包括：`id`、分类和文种、`kind`、`title`、`body`、`referenceAnswer`、排序和发布版本。`referenceAnswer` 只在专项练习中使用。

## 版本与权限

- 稳定内容编号不能修改，历史发布修订不能编辑或删除。
- 现有全题库永久权益服务统一授权，不新增独立商品或期限。
- 应用文后台权限为 `writing.view_writingcontent`、`writing.change_writingcontent` 和 `writing.publish_writingcontent`，分类、文种和历史修订沿用各自查看/编辑权限。
- OpenAPI 文件已同步：`doc/api/student-v1.openapi.json`。
